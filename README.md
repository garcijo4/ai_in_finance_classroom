# Top 10 AI Applications for Finance Classroom Instruction

Companion website for the implementation guide by John Garcia, California Lutheran University.

**Live site:** [garcijo4.github.io/ai_in_finance_classroom](https://garcijo4.github.io/ai_in_finance_classroom/)

## About

This guide synthesizes the top 10 AI applications for finance classroom instruction, ranked by instructional impact (40%), feasibility (35%), and strength of evidence (25%). Each application includes complete implementation details, ready-to-use prompts, assessment rubrics, and first-week pilot instructions.

Prepared for the Southwestern Finance Association Annual Meeting, March 2026.

## Site Structure

- **Home** — Overview and ranking table
- **Applications** — Full detail for all 10 applications
- **Prompt Library** — All sample prompts with one-click copy
- **Quick Start** — First-week implementation pilots
- **References** — Complete reference list
- **About** — Author info and downloads
